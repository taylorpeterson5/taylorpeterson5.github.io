Space Guardian

Unity · C# · Undergraduate class project

A top-down space shooter I built in Unity with C# for a game development class as an undergraduate. Waves of enemy ships fly in along set paths and fire back while you dodge and shoot, and the game keeps score across a start menu, the game itself, and a game-over screen.

How to play

  • Click the game first so it can read your keyboard.
  • Move: arrow keys or W A S D
  • Fire: hold the space bar

What I built

  • Player movement kept inside the camera's view, with continuous fire while the button is held.
  • Enemy waves defined as reusable configurations (ScriptableObjects) that set each wave's ship, flight path, count, and speed.
  • Enemies that fire at random intervals and explode when they're destroyed.
  • A score that carries across scenes.

In 2026 I upgraded the project from Unity 2019 to Unity 6 so it runs in the browser, and fixed a bug where the health counter dropped when you hit an enemy instead of when you got hit. The browser version plays without sound.

Ship, laser, and background art by Kenney (CC0).
